~Query

Change rows. Read the SQL. Save once.

Edits wait as Pending Edits until you press Save. Nothing is written before that.

On Production
Save becomes Save on PROD and asks before it writes.
+4

~Diagram boards

Several diagrams. One board.

Several kinds of diagram share one canvas, each in its own frame. A name used in more than one frame lights up in all of them.

Stuck on a diagram? Ask.

Ask in plain words where something happens, or what a frame is missing. The answer names the frames it read from.

+5

~Data

Every type reviewed, then one transaction.

Data Transfer copies structure, rows or both between Connections, also across Dialects. Each column's source type sits beside the type it will become, and a column with no safe match waits for your choice. If one row does not fit, the run stops there and rolls back.

Also in Data
Import and Export with the first lines shown before the file is written, Backup and Restore that checks the target first, Lineage and Explain.
Across Dialects
MySQL, PostgreSQL and SQLite, in any direction the types allow.
+6

~AI

Each Connection decides what leaves the PC.

Use Anthropic, OpenAI-compatible, Groq, DeepSeek or a local model, with your own key in the system keyring. Each Connection sets what the assistant may see.

It writes SQL and never runs it.

Every answer keeps its trace.

Open any answer's log to see what was sent, what came back and every step between, as Log, Steps or Diagram.

+7

~Safety

Production asks. Read‑only refuses.

On a Production Connection every write waits for your yes, with the exact SQL in front of you. On a Read-only one, writes never run.
