~The habit

One habit for everyone who opens the database.

Developers write the SQL. Analysts drag tables onto a canvas. Support and product people ask a question in plain words.

Contura treats all three the same way: it shows you the SQL first, then waits for you to press Run.

  1. 01

    Say what you need

    Type SQL with completion, drag tables so Contura draws the joins from your Foreign Keys, or ask the assistant. All three end as SQL you can read.

  2. 02

    Read what will happen

    Grid edits wait as Pending Edits with their SQL one click away. A statement that would change every row asks first. On a Production Connection, every write is shown in full before it runs.

  3. 03

    Run it, or don't

    Nothing runs until you press Run or Save. The assistant writes SQL and never runs it. Pending Edits save together, in one transaction.

~Download

For Windows and Linux. Run it from any folder you like.

On Windows, Contura is one exe with no installer. On Linux it is one AppImage, or a .deb if you prefer a package. Settings, Connections, Query History and Saved Queries live in a data folder beside the exe or the AppImage, so copying the folder takes your setup along.
