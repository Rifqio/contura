~01 · Schema Builder

Type the model. Watch it draw.

The Schema Builder keeps a model as DBML, a short text format for tables, columns and the Refs between them. Contura draws the diagram from the text and keeps the two in step.

Start from an empty file, or reverse engineer a Connection into DBML. When the model is right, export it as a SQL script, or as an image of the diagram.

From a database
Reverse engineer any Connection into DBML.
Out of it
A SQL script to create the tables, or a PNG or SVG image.

~02 · Schema Compare

Tick the Sync Script, line by line.

Schema Compare reads two databases of the same Dialect and lists what is added, removed or changed. Every change becomes one statement in the Sync Script, with its own tick.

Unticking a change also unticks the changes that need it. A change that loses data starts unticked, and on a Production Connection Apply shows every statement before anything runs.

Same Dialect
Two databases of one Dialect, such as a development copy and staging.
Data loss
Starts unticked, and says how many rows it would touch.

~03 · Diagrams

Eight kinds of diagram, typed as text.

The first line of a .flow file picks the kind: flow, dfd, sequence, state, class, mindmap, timeline or cloud. The canvas redraws as you type, and a name that does not match shows as a problem under it. Entity relationship diagrams live in the DBML Schema Builder above.

Where each node sits lives in a .flow.layout.json beside the text, so moving a node leaves the text alone. A diagram stays one file you can read, diff and keep in git.

  • One text fileA diagram is a .flow file you can read, diff and keep in git.
  • Layout beside itNode places live in a .flow.layout.json, so moving a node leaves the text alone.
  • PublishSave or copy a diagram as PNG or SVG, in the Light or Dark colours.
  • From MermaidPaste a Mermaid flowchart and get a .flow file back.

~04 · From Mermaid, out to an image

Paste a flowchart in. Publish a picture out.

New flow from Mermaid reads a pasted flowchart and shows the diagram it becomes beside it. Anything without a match is listed with its line, and a line Contura cannot read is named before you create the file.

Publish saves or copies a diagram as PNG or SVG, in the Light or Dark colours, at the scale you pick.
